# DBL Design Process References

本資料夾存放 Design-Based Learning（DBL）在本 Skill 中的設計流程與判斷規則。

DBL 在本 Skill 中的定位不是單一教學策略，
而是整合課程目標、問題界定、挑戰任務、評量規準、學生嘗試、課程教學與設計修正的整體迭代機制。

本 Skill 使用的核心流程為：

1. 什麼是我要教的
2. 界定一個問題
½. 提出一個前所未見的挑戰任務
3. 評定評量規準
4. 讓學生嘗試
5. 引導課程教學
6. 學生調整設計

DBL 與其他模組的分工：

- Backward Design：協助建立 Big Idea、KU、EQ、Evidence、Criteria
- Gifted Education：協助判斷加深加廣與高能力發展方向
- DBL：將上述設計放入問題—挑戰—嘗試—教學—修正的循環
- DI：依學生實際學習證據回應差異

本資料夾中的內容應忠實依據本專案採用的 DBL 6½ 步驟版本。

不得自行以其他 DBL 模型取代。
