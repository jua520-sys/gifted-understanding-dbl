# Learning Core｜把關鍵理解轉成可教的學習內核

## Purpose

本文件用來把已選定的關鍵理解，轉成真正能驅動課程設計的學習內核。

目的不是立刻產生活動，而是回答：

- 學生到底要理解什麼？
- 學生需要知道什麼？
- 學生需要會做什麼？
- 教師需要提供什麼素材與經驗？
- 哪些內容可以壓縮或刪除？
- 對資優生而言，高能力可以往哪裡發展？

Learning Core 是關鍵理解與後續核心問題、NBS、學習證據之間的橋梁。

---

## 1. Understand｜學生最終要理解什麼？

將關鍵理解轉成更貼近學習者的語言。

這一欄要回答：

「如果課程成功，學生最後真正懂了什麼？」

不是重寫活動，也不是能力動詞。

例如：

關鍵理解：
資訊揭露的先後可能改變讀者形成與修正推論的方式。

Understand：
學生理解：
- 同一事件不等於同一閱讀經驗。
- 讀者何時知道什麼，會影響當下形成的解釋。
- 新資訊會使原有線索被重新理解。
- 作者可以透過敘事安排影響讀者推論。

---

## 2. Know｜學生需要知道什麼？

列出支撐關鍵理解所不可缺少的知識。

可能包括：

- 重要概念
- 關鍵術語
- 文本特徵
- 規則
- 原理
- 背景知識
- 重要事實
- 學科慣例
- 判斷所需資訊

只列真正服務關鍵理解的知識。

不要把整個教材目錄全部搬進來。

### 判斷問題

每一項 Know 都要問：

「如果學生不知道這個，他會不會因此難以形成或運用關鍵理解？」

若不會，可能不是核心 Know。

---

## 3. Do｜學生需要會做什麼？

列出學生為了形成與展現理解，需要執行的學科工作。

可能包括：

- 比較
- 分析
- 推論
- 舉證
- 詮釋
- 建模
- 論證
- 判斷
- 設計
- 創作
- 檢驗
- 修正
- 反駁
- 一般化
- 問題重構

注意：

Do 不是關鍵理解本身。

例如：

「能比較不同文本」

不是 Understanding。

但可能是學生形成 Understanding 所必須使用的學科工作。

---

## 4. Materials / Experiences｜教師需要提供什麼？

這一欄回答：

「學生若要真的形成這個理解，教師必須提供什麼類型的素材與經驗？」

可能包括：

- 文本
- 案例
- 反例
- 對照案例
- 資料
- 圖表
- 模型
- 實驗
- 問題情境
- 真實作品
- 不完整作品
- 學生作品
- 讀者／使用者回饋
- 多種觀點材料

重點不是「越多越好」。

應選擇能讓學生看見關鍵關係、機制、張力或差異的素材。

---

## 5. 可以壓縮、延後或刪除什麼？

Learning Core 不只用來增加內容，也要幫助刪除內容。

問：

- 哪些背景知識只需要簡要交代？
- 哪些分類活動對理解沒有直接貢獻？
- 哪些練習只是重複？
- 哪些教材雖有趣，但不服務核心理解？
- 哪些細節可以移到補充材料？

如果什麼都不能刪，代表 Learning Core 可能仍不夠聚焦。

---

## 6. Gifted Growth｜高能力如何進一步發展？

這一欄專門處理資優課程的發展價值。

不要只寫：

- 更難
- 更多
- 更快
- 更複雜

而要問：

「這個單元如何讓學生在該領域中，展現質的不同的高層次能力？」

可以從以下方向思考：

### 從表面到結構

- 從辨認 → 解釋
- 從套用 → 看見結構
- 從結果 → 理解機制
- 從單一答案 → 多重解釋

### 從接受到判斷

- 從接受規則 → 判斷規則何時適用
- 從使用證據 → 評估證據品質
- 從回答問題 → 重構問題
- 從完成任務 → 作出設計決策

### 從單一路徑到多種可能

- 比較不同方法
- 建立替代模型
- 提出不同解釋
- 找出例外
- 處理不確定性
- 面對互相衝突的證據

### 從個案到遷移

- 跨案例
- 跨文本
- 跨情境
- 跨表徵
- 跨方法
- 跨領域

---

## 7. 一般表現與高層次表現

AI 應避免把所有學生都預設為同一種卓越表現。

可以區分：

### 一般理解表現

學生能：
- 正確說明核心原理
- 在熟悉案例中使用
- 提供基本證據
- 完成核心任務

### 高層次表現可能包括

學生能：
- 發現未被明說的關係
- 提出替代解釋
- 找出限制與例外
- 評估證據品質
- 重構問題
- 建立新模型
- 進行跨情境遷移
- 根據真實回饋修正作品
- 作出具有理由的設計決策

不是每位學生都必須以相同方式展現高能力。

---

## 8. Learning Core 與後續設計的關係

完成 Learning Core 後，才能更精準地進入：

關鍵理解
↓
核心問題
↓
NBS／真實表現任務
↓
學習證據
↓
評量規準

核心問題應打開 Understand 中的重要關係。

NBS 應迫使學生同時使用：
- Know
- Do
- Understanding

學習證據則應能看見：
- 學生是否真的形成 Understanding
- 是否能運用 Know
- 是否能執行有品質的 Do

---

## 10. 判斷要求

AI 不得：

- 把 Know 變成整本教材目錄
- 把 Do 當成 Understanding
- 把 Materials 變成活動清單
- 把 Gifted Growth 寫成「更難、更快、更多」
- 假設所有資優生都應展現同一種高能力

若 Learning Core 無法清楚回答：

「學生到底要學什麼？」
「教師到底要提供什麼？」
「這個單元如何讓高能力往前發展？」

則必須重新修訂。
