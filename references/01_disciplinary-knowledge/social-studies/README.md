# Social Studies Disciplinary Knowledge

本資料夾存放社會領域正式課程依據、領域定位、課綱索引與課程設計詮釋。

本資料夾的用途不是把社會課綱簡化成代碼清單，而是協助 Skill 依序理解：

正式課綱
→ 社會領域本質
→ 學習階段與正式課程要求
→ 社會領域中的高能力與加深加廣
→ Big Idea
→ 關鍵理解 KU
→ 核心問題 EQ
→ NBS／真實表現任務
→ 學習證據
→ 評量規準

## Source of Truth

正式社會領綱原始文件放置於：

`source/`

若本資料夾中的任何整理內容與正式領綱原文不一致，
以正式領綱原文為準。

## Planned Structure

- `source/`：正式社會領域課程綱要原始文件
- `01_domain_orientation.md`：社會領域基本理念、課程目標與領域本質
- `02_curriculum_index.md`：第二、第三學習階段為主，第四學習階段作延伸參照
- `03_design_interpretation.md`：從正式課綱進入資優社會課程設計的判斷原則

若後續確認有必要，
才新增社會領域專屬補充 framework。

不得為了資料夾形式對稱而預先建立不必要的補充檔案。
