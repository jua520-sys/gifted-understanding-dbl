# 國語文領域課綱資料說明

## Purpose

本資料夾用來存放「國語文領域」正式課綱與本 Skill 所需的結構化整理資料。

本資料夾的用途不是取代正式課綱，而是讓 Skill 在進行課程設計前，能先確認：

1. 本單元屬於哪一個學習階段？
2. 哪些學習表現與本單元最直接相關？
3. 哪些學習內容與本單元最直接相關？
4. 哪些內容是正式課綱要求？
5. 哪些內容是教師或 AI 後續的課程詮釋？

---

## Source of Truth

正式課綱原文優先於 AI 整理。

若整理內容與正式課綱原文不一致，應以正式課綱原文為準。

每次引用課綱時，應盡可能保留：

- 正式代碼
- 正式文字
- 學習階段
- 領域
- 文件名稱
- 版本或發布資訊
- 來源

不得把模型一般知識冒充正式課綱內容。

---

## 建議資料結構

本資料夾後續可加入：

- `source_info.md`
  - 正式課綱名稱
  - 版本
  - 發布單位
  - 來源
  - 整理日期

- `learning_performance.md`
  - 國語文相關學習表現
  - 依學習階段整理
  - 保留正式代碼與原文

- `learning_content.md`
  - 國語文相關學習內容
  - 依學習階段整理
  - 保留正式代碼與原文

- `core_competencies.md`
  - 若正式設計需要，可整理相關核心素養

- `disciplinary_notes.md`
  - 本 Skill 對國語文領域本質的設計提示
  - 必須清楚標示為「課程詮釋」，不能假裝是課綱原文

---

## Skill 使用規則

當使用者設計國語文課程時：

1. 先確認學習階段。
2. 讀取本資料夾中的正式課綱整理。
3. 找出最直接相關的學習表現與學習內容。
4. 清楚區分：
   - 課綱原文
   - 課程設計詮釋
5. 再進入：
   - Gifted Learner Horizon
   - 加深加廣
   - Big Idea
   - 關鍵理解
   - 核心問題
   - NBS
   - 學習證據
   - 評量規準

不得先生成完整課程，再回頭勉強找課綱對位。

## 注意事項
本 Skill 的國語文正式課綱使用範圍以第二、第三學習階段為主。
第四學習階段僅作為資優學生可能的加速、加深或延伸參考，
不得直接視為所有國小資優生都應達成的基本要求。
