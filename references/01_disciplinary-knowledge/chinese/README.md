# 國語文領域課綱資料說明

## Purpose

本資料夾用來存放「國語文領域」正式課綱，以及本 Skill 進行課程設計時所需的結構化導航與設計解讀。

本資料夾的目的不是取代正式課綱，而是讓 Skill 在進入資優課程逆向設計前，先確認：

1. 本單元屬於哪一個學習階段？
2. 國語文領域的基本理念與課程目標是什麼？
3. 哪些學習表現與本單元最直接相關？
4. 哪些學習內容與本單元最直接相關？
5. 哪些內容是正式課綱要求？
6. 哪些內容是教師或 AI 後續的課程設計詮釋？

---

## Source of Truth

正式課綱原文優先於任何 AI 整理或課程設計詮釋。

若整理內容與正式課綱原文不一致，應以正式課綱原文為準。

每次引用課綱時，應盡可能保留：

- 正式代碼
- 正式文字
- 學習階段
- 領域
- 文件名稱
- 版本或發布資訊
- 來源

不得把模型一般知識冒充正式課綱內容。

---

## 本資料夾結構

本資料夾採「正式來源＋領域定位＋課綱導航＋設計詮釋」四層結構。

### `source/`

存放正式國語文領綱原始文件。

正式原始文件為本資料夾最高優先來源。

### `01_domain_orientation.md`

整理跨學習階段的國語文領域定位，包括：

- 基本理念
- 課程目標
- 領域學習的基本結構
- 國語文作為語言、文學、文化、溝通與思辨領域的核心精神

此檔案的功能是避免 Skill 只把國語文課綱當成「學習表現／學習內容代碼資料庫」。

---

### `02_curriculum_index.md`

整理本 Skill 實際使用的國語文課綱索引。

正式使用範圍：

- 第二學習階段：國小3–4年級
- 第三學習階段：國小5–6年級
- 第四學習階段：國中7–9年級，僅作為資優學生可能的加速、加深或延伸參考

索引內容應保留：

- 正式代碼
- 正式文字
- 學習階段
- 學習表現類別
- 學習內容類別

索引的功能是幫助 Skill 快速定位正式課綱內容，不取代正式原始文件。

---

### `03_design_interpretation.md`

整理本 Skill 如何使用國語文課綱進行資優課程設計。

此檔案屬於「課程設計詮釋」，不是課綱原文。

設計時至少同時檢查：

1. 領域精神
2. 學習表現
3. 學習內容
4. 資優學生可能的領域高能力
5. 加深與加廣方向
6. 後續 Big Idea、關鍵理解、核心問題、NBS、學習證據與評量規準的對位

## 國語文領域使用範圍

本 Skill 的國語文正式課綱使用範圍以：

- 第二學習階段
- 第三學習階段

為主要設計依據。

第四學習階段僅作為：

- 加速
- 加深
- 延伸
- 高準備度學生的進階參考

不得直接視為所有國小資優生都應達成的基本要求。

不得把「資優」簡化為直接提前教授國中課程內容。

---

## Skill 使用規則

當使用者設計國語文課程時，依以下順序進行：

1. 確認學生年級與學習階段。
2. 讀取 `01_domain_orientation.md`，確認國語文領域精神。
3. 讀取 `02_curriculum_index.md`，找出最直接相關的學習表現與學習內容。
4. 必要時回到 `source/` 中的正式領綱查核原文。
5. 清楚區分：
   - 正式課綱原文
   - 本 Skill 的課程設計詮釋
6. 再進入：
   - Gifted Learner Horizon
   - 領域高能力
   - 加深加廣
   - Big Idea
   - 關鍵理解
   - 核心問題
   - NBS／真實表現任務
   - 學習證據
   - 評量規準

不得先生成完整課程，再回頭勉強尋找課綱對位。

## 國語文課綱的基本結構

國語文的學習重點由「學習表現」與「學習內容」共同構成。

學習表現包含：

- 聆聽
- 口語表達
- 標音符號與運用
- 識字與寫字
- 閱讀
- 寫作

學習內容則包括：

- 文字篇章
- 文本表述
- 文化內涵

正式課程設計時，不宜只抓單一學習表現或單一學習內容，而應思考兩者如何共同形成學生的國語文學習。
