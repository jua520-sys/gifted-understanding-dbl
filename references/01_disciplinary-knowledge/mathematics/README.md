# Mathematics Disciplinary Knowledge

本資料夾存放數學領域正式課程依據、領域定位、課綱索引與課程設計詮釋。

本資料夾的用途不是把數學課綱簡化成代碼清單，而是協助 Skill 依序理解：

正式課綱
→ 數學領域本質
→ 學習階段與正式課程要求
→ 數學中的高能力與加深加廣
→ Big Idea
→ 關鍵理解 KU
→ 核心問題 EQ
→ NBS／真實表現任務
→ 學習證據
→ 評量規準
