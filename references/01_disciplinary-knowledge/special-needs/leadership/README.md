## Formal Curriculum Structure

領導才能課程的學習表現包含三個主要向度：

1. 任務導向
2. 關係導向
3. 變革導向

正式課綱並依上述向度發展相關的學習表現與學習內容。

因此領導才能不能只被理解為：

- 當組長
- 上台報告
- 指揮別人
- 辦活動
- 人緣好

而是一門涉及：

- 目標
- 任務
- 計畫
- 決策
- 角色
- 責任
- 溝通
- 團隊關係
- 衝突處理
- 願景
- 變革
- 行動

的正式課程。

## Stage Use

領導才能課綱中的學習階段屬於參酌性質。

教師應依：

- 學生需求
- 先備經驗
- 能力
- 領導經驗
- 素質涵養現況

跨階段選用與調整適合的學習表現與學習內容。

不得把跨階段直接理解為：

> 資優生應該接受更高年級的領導訓練。

跨階段必須有學生需求與準備度證據。

## Skill Use

設計領導才能課程時：

1. 先讀 `../00_shared_orientation.md`
2. 再讀本資料夾的領導才能 reference
3. 回到正式領綱查核
4. 先判斷學生目前真正的領導發展需求
5. 再選學習表現與學習內容
6. 必要時跨階段選取
7. 再進入 Big Idea、KU、EQ、NBS、Evidence、Criteria

領導才能課程不應從：

> 「誰最像領導者？」

開始。

而應從：

> 「在真實團隊與任務中，學生需要發展什麼樣的影響、責任、關係與變革能力？」

開始。
