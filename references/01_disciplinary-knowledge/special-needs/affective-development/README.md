## Formal Curriculum Structure

情意發展課程的學習表現包含：

- 4 個向度
- 15 個次項目

正式領綱的學習內容則規劃為四大主題：

1. 認識才能發展｜特情 A
2. 面對挑戰與生涯發展｜特情 B
3. 溝通互動、生活效能與美感｜特情 C
4. 適應環境並參與社會｜特情 D

因此情意發展不能只被理解為：

- 情緒教育
- 心情分享
- 自我肯定活動

而是一門涉及：

- 才能發展
- 自我理解
- 情緒與壓力
- 韌性
- 動機
- 生涯
- 溝通與同理
- 資訊與媒體
- 美感
- 社會適應
- 文化認同
- 公共參與

的正式課程。

## Stage Use

情意發展課綱中的學習階段屬於參酌性質。

教師應依：

- 學生需求
- 先備經驗
- 能力
- 素質涵養現況

跨階段選用與調整適合的學習表現與學習內容。

不得把跨階段直接理解為：

> 資優生應該往高年級教。

跨階段必須有學生需求與準備度證據。

## Skill Use

設計情意發展課程時：

1. 先讀 `../00_shared_orientation.md`
2. 再讀本資料夾的情意發展 reference
3. 回到正式領綱查核
4. 先判斷學生真正的情意發展需求
5. 再選學習表現與學習內容
6. 必要時跨階段選取
7. 再進入 Big Idea、KU、EQ、NBS、Evidence、Criteria

情意發展課程不應從：

> 「資優生通常有什麼問題？」

開始。

而應從：

> 「目前這位學生或這群學生，有什麼可被觀察與支持的發展需求？」

開始。
