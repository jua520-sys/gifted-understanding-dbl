# Gifted Special Needs Domain

本資料夾存放「資賦優異相關之特殊需求領域課程綱要」及其四個正式科目的課程設計參照。

本領綱包含四個科目：

- 情意發展
- 領導才能
- 創造力
- 獨立研究

四個科目共用同一份正式領綱，
但各自具有不同的：

- 課程目標
- 核心素養
- 學習表現
- 學習內容
- 課程設計重點

因此本 Skill 不把四科視為完全相同的課程結構。

## Shared Design Principle

本領綱與一般學科最大的差異之一是：

> 學習階段屬於參酌性質，
> 教師可依學生能力、先備經驗與學習需求，
> 跨階段選取與調整適合的學習表現與學習內容。

因此不得機械地以年級限制課程設計。

跨階段選取時仍需有：

- 學生需求證據
- 能力與準備度依據
- 課程目的
- 適切性判斷

不得把「資優」直接等同於「往高年級搬內容」。

## Four Subjects

### Affective Development｜情意發展

重點包含：

- 自我認識
- 優弱勢與期待
- 情緒
- 壓力與韌性
- 動機
- 生涯
- 溝通與同理
- 資訊運用
- 社會適應與參與

---

### Leadership｜領導才能

重點包含：

- 任務導向
- 關係導向
- 變革導向
- 角色與目標
- 計畫與監督
- 團隊支持
- 團隊發展
- 願景與行動

---

### Creativity｜創造力

重點包含：

- 創造性人格
- 擴散與聚斂思考
- 創意成果
- 創意評鑑
- 創意資源
- 支持創造力的環境

---

### Independent Research｜獨立研究

重點包含：

- 研究態度
- 問題形成
- 研究方法
- 資料蒐集與分析
- 解釋
- 成果表達
- 研究評鑑
- 研究倫理

## Skill Use Rule

當使用者指定特殊需求領域時：

1. 先確認是哪一個正式科目。
2. 讀取 `00_shared_orientation.md`。
3. 再讀該科目的 reference。
4. 回到正式領綱核對。
5. 依學生需求決定是否跨階段選取。
6. 再進入 Big Idea、KU、EQ、NBS、Evidence、Criteria。
